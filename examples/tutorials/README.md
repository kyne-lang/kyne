# examples/tutorials/

Small, single-concept example contracts written to teach one Kyne
construct at a time — a single-function contract demonstrating only
`auth`, a single-function contract demonstrating only `match`, and so on —
per [`ARCHITECTURE.md` §7](../../ARCHITECTURE.md#7-examples).

Distinct from [`examples/canonical/`](../canonical/): tutorial examples
exist to teach, not to specify, and are not part of the compiler's
golden-file test corpus. They support
[`FOUNDATION.md`](../../docs/FOUNDATION.md#success-metrics)'s "first
contract within one hour" goal.

**No tutorial examples exist yet.** This directory is created empty
during Phase 1 — Milestone 1 (Workspace Initialization) as a placeholder
with a defined purpose, ready to receive content as the compiler becomes
able to validate it.
