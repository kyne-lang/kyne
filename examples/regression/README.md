# examples/regression/

One `.kyn` file per fixed compiler defect whose triggering pattern is not
already covered by [`examples/canonical/`](../canonical/) or
[`examples/tutorials/`](../tutorials/), per
[`ARCHITECTURE.md` §7](../../ARCHITECTURE.md#7-examples) — the
example-source counterpart to `tests/regression/`'s test-side assertions.

**No regression examples exist yet.** There is no compiler yet to have
produced a defect for one of these files to capture, per
[`ROADMAP.md` §13](../../docs/ROADMAP.md#13-testing-roadmap)'s "every
fixed defect gets a permanent regression test" rule. This directory is
created empty during Phase 1 — Milestone 1 as a placeholder with a
defined purpose.
